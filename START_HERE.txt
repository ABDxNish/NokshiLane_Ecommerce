NOKSHILANE E-COMMERCE
=====================

STACK
-----

Frontend:
Next.js
React
TypeScript
React Hook Form
Zod
Axios
Pusher Client
Custom responsive CSS

Backend:
NestJS
TypeScript
PostgreSQL
TypeORM
class-validator
express-session
bcrypt
Google Sign-In
Pusher
Nodemailer

Payment:
Cash on Delivery
SSLCOMMERZ Hosted Checkout


============================================================
STEP 1 — CREATE POSTGRESQL DATABASE
============================================================

Open pgAdmin Query Tool and run:

CREATE DATABASE nokshilane_ecommerce;


============================================================
STEP 2 — BACKEND ENV
============================================================

Open terminal:

cd backend

Windows CMD:

copy .env.example .env

PowerShell:

Copy-Item .env.example .env

Then open:

backend/.env

Set at least:

DB_PASSWORD=YOUR_POSTGRES_PASSWORD

You can leave Google, Pusher, Mail and SSLCOMMERZ empty
during the first run.


============================================================
STEP 3 — INSTALL + SEED BACKEND
============================================================

Inside backend:

npm install

Then:

npm run seed

Then:

npm run start:dev


Backend runs at:

http://localhost:3001


============================================================
STEP 4 — FRONTEND ENV
============================================================

Open another terminal:

cd frontend

Windows CMD:

copy .env.local.example .env.local

PowerShell:

Copy-Item .env.local.example .env.local


============================================================
STEP 5 — INSTALL + START FRONTEND
============================================================

Inside frontend:

npm install

Then:

npm run dev


Frontend runs at:

http://localhost:3200
